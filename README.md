# Expense Tracker

A full-stack expense tracking application built with Next.js, React, and Neon Database.

## Features

- User authentication
- Create and manage budgets
- Add and track expenses
- Dashboard with expense summaries
- Responsive design

## Tech Stack

- Next.js
- React
- JavaScript
- Neon PostgreSQL
- Drizzle ORM
- Tailwind CSS
